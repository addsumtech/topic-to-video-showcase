# video.addsum.top: topic-to-video films

The showcase site for [topic-to-video](https://github.com/addsumtech/topic-to-video), served by GitHub Pages at <https://video.addsum.top> (Chinese at `/cn/`).

It shows eight films the skill made, in two sections:

- **Remotion**: each shot is a React component rendered frame by frame; heavier 3D shots are rendered in Blender. WorkBuddy, topic-to-video, slide-maker, Grok Bot, noise cancelling, job-hunt.
- **HTML**: each beat is a web page animated in headless Chrome and captured frame by frame. QR codes, MRI.

The films are in `films/`, re-encoded to 1080p H.264 for the web, and their poster frames are in `posters/`. Both pages are generated by `python3 tools/build.py` from the list at the top of that script. Edit the list, then rebuild.

The WorkBuddy and Grok Bot films are independent work, not affiliated with Tencent or xAI. Product names belong to their owners.
