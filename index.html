Films made from a single request

Each film began as one request in a chat. topic-to-video researched the subject, wrote and voiced the script, designed every shot and rendered the video. No frame was animated by hand.

Remotion films

Each shot is a React component rendered frame by frame with Remotion, picked from a library of 225 shot designs or built for the film. Heavier 3D shots are rendered in Blender.
